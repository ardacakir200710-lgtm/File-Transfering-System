# P2P File Transfer

**Secure, simple, and efficient file sharing between computers.**

P2P File Transfer is a Python-based desktop application that enables secure file and folder transfers between computers through an intuitive graphical user interface.

Built with **Tkinter** and powered by [Magic Wormhole](https://github.com/magic-wormhole/magic-wormhole), the application provides end-to-end encrypted file transfers without requiring port forwarding, static IP addresses, or complicated network configurations.

## Features

- **End-to-End Encryption:** Secure file transfers powered by Magic Wormhole.
- **No Port Forwarding Required:** Transfer files without manually configuring router ports.
- **File and Folder Transfers:** Send individual files or entire directories.
- **One-Time Transfer Codes:** Connect sender and receiver using a temporary authentication code.
- **Modern Graphical Interface:** User-friendly desktop application built with Tkinter.
- **Real-Time Progress Tracking:** Monitor transfer progress, speed, and elapsed time.
- **Multilingual Support:** Switch between English and Turkish.
- **Dark and Light Themes:** Customize the application's appearance.
- **Transfer History:** Automatically record application events and transfer activities.
- **Transfer Cancellation:** Cancel ongoing transfers at any time.
- **Command-Line Interface:** Send and receive files directly through the terminal.
- **File Protection:** Received files are saved in separate folders to avoid overwriting existing files in GUI mode.

## Installation

### 1. Clone the Repository

Clone the repository or download the source code.

```bash
git clone <REPOSITORY_URL>
cd <PROJECT_FOLDER>
```

### 2. Install Dependencies

Install Magic Wormhole using pip:

```bash
python -m pip install --upgrade "magic-wormhole>=0.23.0"
```

Magic Wormhole must be installed on both the sending and receiving computers.

### 3. Run the Application

```bash
python dosya_aktar.py
```

The graphical user interface will launch automatically.

## How to Use

### Sending Files

1. Launch the application on the sending computer.
2. Navigate to the **Send Files** tab.
3. Select the file or folder you want to transfer.
4. Click **Start Sending**.
5. Wait for the application to generate a one-time transfer code.
6. Share the generated code with the receiver.
7. The transfer begins once the receiver enters the code and connects.
8. Monitor the transfer progress until completion.

### Receiving Files

1. Launch the application on the receiving computer.
2. Navigate to the **Receive Files** tab.
3. Enter the transfer code provided by the sender.
4. Select the destination directory.
5. Click **Receive Files**.
6. Wait for the transfer to complete.
7. Click **Open Received Folder** to access the downloaded files.

By default, received files are stored in:

```text
Downloads/
└── Gelen_Dosyalar/
    └── Alinan_YYYYMMDD_HHMMSS_.../
        └── Received_File
```

Each transfer performed through the graphical interface creates a separate destination folder.

## Command-Line Usage

The application also supports file transfers directly from the terminal.

### Send a File

```bash
python dosya_aktar.py gonder "C:\Files\example.zip"
```

### Send a Folder

```bash
python dosya_aktar.py gonder "C:\Files\Project"
```

### Receive a File

```bash
python dosya_aktar.py al
```

### Specify a Destination Directory

```bash
python dosya_aktar.py al --klasor "C:\Downloads"
```

### Receive Using a Transfer Code

```bash
python dosya_aktar.py al --kod "7-example-code"
```

**Note:** The transfer code shown above is only an example. Use the actual code generated by the sending computer.

The command-line arguments `gonder`, `al`, `--klasor`, and `--kod` are currently defined in Turkish.

## Security

P2P File Transfer uses the security mechanisms provided by Magic Wormhole.

- **End-to-End Encryption:** Transferred data is encrypted between the sender and receiver.
- **One-Time Authentication Codes:** Each transfer uses a temporary code to establish a secure connection.
- **No Manual IP Configuration:** Users do not need to exchange IP addresses.
- **NAT Traversal:** Magic Wormhole attempts to establish a direct connection when possible.
- **Relay Support:** When direct connectivity is unavailable, transfers may use a relay server while maintaining encryption.

**Security Notice:** Only share transfer codes with trusted recipients. Activity logs may contain local file paths and transfer codes, so they should not be published or shared publicly without review.

## Settings and Activity Logs

Application settings and transfer history are stored locally.

On Windows, the default configuration directory is:

```text
%APPDATA%\KolayDosyaAktarimi\
```

Directory structure:

```text
KolayDosyaAktarimi/
├── settings.json
└── islem_gunlugu.jsonl
```

### settings.json

Stores user preferences, including:

- Application language
- Selected appearance theme

### islem_gunlugu.jsonl

Records application activities such as:

- Application startup and shutdown
- Transfer initiation
- Successful transfers
- Failed transfers
- Cancelled operations
- Error information

The activity history can be viewed directly from the application's **Activity Log** interface.

## How It Works

1. The sender selects a file or directory.
2. The application launches a Magic Wormhole transfer process.
3. Magic Wormhole generates a temporary transfer code.
4. The sender shares the code with the intended receiver.
5. The receiver enters the code to join the transfer session.
6. Magic Wormhole establishes a secure encrypted connection.
7. File transfer begins.
8. The application displays available progress, transfer speed, and elapsed time.
9. The transfer result is recorded in the activity log.

The application uses background threads to execute transfer processes without blocking the graphical user interface.

## Troubleshooting

### Magic Wormhole Not Found

Install or update Magic Wormhole:

```bash
python -m pip install --upgrade "magic-wormhole>=0.23.0"
```

Verify the installation:

```bash
wormhole --help
```

### Invalid Transfer Code

- Make sure the code is entered correctly.
- Verify that the sender's transfer session is still active.
- Generate a new transfer code if the previous session has expired or ended.

### Transfer Does Not Start

- Check the internet connection on both computers.
- Verify that Magic Wormhole is installed on both devices.
- Check whether firewall or network restrictions are interfering with connectivity.
- Review the application activity log for error messages.

### Slow Transfer Speed

Transfer performance depends on several factors:

- Internet upload and download speeds
- Network conditions
- Disk read/write performance
- Whether the connection is direct or relayed

## Known Limitations

- Both computers must have Magic Wormhole installed.
- An internet connection is required.
- Only one transfer can be managed at a time through the application interface.
- Transfer progress and speed reporting depend on the output provided by Magic Wormhole.
- Interrupted transfers cannot automatically resume from where they stopped.
- The application is Windows-focused, and cross-platform compatibility requires further testing.
